# Wonderingland

A quiz website with 1044 questions across 16 categories.

## Features
- 1044 questions, 16 categories
- Relaxing background music (Web Audio API)
- Timed questions with countdown ring
- Answer shuffling on every question
- Category selection & random mix
- Results screen with review & high score tracking (localStorage)
- Keyboard shortcuts (1/2/3/4 to answer)

## Live sites
- GitHub Pages: https://cyberhypnotize.github.io/Wonderingland
- Cloudflare Pages: https://quiz-land.pages.dev

## Run locally
Download `quiz-website.html` and open it in any browser.
